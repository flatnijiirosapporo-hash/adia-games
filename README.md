# にじフラ チャレンジ Ver2.5 - 継続支援・評価漏れ防止・経過確認版

## 起動方法
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. ゲームまたはSSTを選びます。

インストールや外部ライブラリは不要です。新規ゲームはオフラインで動作します。

## 参考情報
参考サイト: 特別支援教材開発研究所（TKK） https://tkk-fk.com/
確認日: 2026-08-26

TKKで公開されているゲーム系教材の「学習目的・ルール・操作の考え方」を参考にし、コード・画面・素材はにじフラ用に独自実装しています。TKKのHTML/CSS/JavaScriptや画像素材をコピーしたものではありません。

## Ver2.5 問題バンク500問化（2026-09-02）

### 出題規模
- TOPゲームカード: 86
- 固定問題バンク型: 31ゲーム（各500問。原則 かんたん200 / ふつう200 / チャレンジ100）
- 自動生成型: 13ゲーム（各500通り以上を保証）
- 既に十分な問題空間があるゲーム: 4ゲーム（国旗ゲーム、数字ハイアンドロー等）
- 反応・運動・自由操作など500問化が不適切なゲーム: 38ゲーム（ゲーム性を維持）

### ランダム出題・重複防止
- 問題型ゲームはプレイ開始時にランダム抽出します。
- 同一プレイ内の重複を防止します。
- 端末内に出題履歴を保持するシャッフルバッグ方式を採用し、原則として問題を一巡するまで同じ問題の再出題を避けます。
- 問題バンクの版が変わった場合は、新しい問題IDを取り込みながら履歴を安全に再構成します。

### 品質・安定性
- 固定問題バンクはID重複・実質重複・選択肢重複・正解不整合を自動検査します。
- 算数・生活系の自動生成ゲームは、500通り以上の一意問題キーと正解再計算を自動検証します。
- 問題データと出題処理は配布HTMLへ内包し、GitHub Pagesやローカル起動時の外部データ読込失敗を減らしています。
- かたちパズルは300問から500問（200 / 200 / 100）へ拡張しました。
- 国旗ゲームは201の国・地域と5モードを維持し、問題数目的の水増しはしていません。
- 数字ハイアンドローは、かんたん1〜10 / ふつう1〜50 / チャレンジ1〜100 の3難易度です。

## 操作統一
- 各ゲームの開始は「スタート」に統一
- ゲーム開始後、最初のスタートボタンは非表示
- 終了型ゲームでは「もう1回」を表示
- 「もう1回」押下時に「周りにやりたい友達がいないか確認してね」を確認してから再開
- TOP以外にVer表記なし

## 推奨運用
1. 児童がゲームまたはSSTを実施
2. 終了後に「結果・評価を印刷」へ進む
3. 職員が観察評価・メモ・次回のねらいを入力
4. 必要に応じてA4印刷
5. `records.html` で未評価記録を確認し、`child_summary.html` で児童別の経過を振り返る
6. 定期的にJSONバックアップを保存
7. 集計が必要な場合はCSV出力

## 保存データについて
データは使用しているブラウザのローカルストレージに保存します。クラウド送信は行いません。
ブラウザのデータ消去、端末変更、別ブラウザ利用では自動的には引き継げません。JSONバックアップを利用してください。

児童名などの個人情報を入力する場合は、共有端末の管理、端末の紛失対策、バックアップファイルの保存先を事業所の個人情報管理ルールに沿って管理してください。

## 評価上の注意
ゲームの点数、正答率、成功・失敗だけで児童の能力や療育上の評価を決める仕様にはしていません。
ゲーム結果は客観結果として扱い、療育上の評価は、実際の行動、必要な支援量、場面理解、切り替え、自己調整、般化状況などを職員が観察して記録してください。

## Windowsでの推奨起動方法
記録履歴・A4評価・CSV/バックアップを継続利用する場合は、ZIP展開後に `START_NIJIFLA.bat` をダブルクリックしてください。

同梱の `start_nijifla.ps1` が `127.0.0.1` のローカルWebサーバーを起動し、ブラウザで自動的に開きます。外部ネットワークには公開しません。起動したPowerShell画面を閉じるとサーバーも終了します。

`index.html` を直接開く方法も残しています。ただし `file://` でのローカルストレージの扱いはブラウザ実装に依存するため、複数HTML間で長期の記録履歴を共有する用途ではローカルWebサーバー起動または通常のWebサーバーへの設置を推奨します。

ゲーム終了直後のA4結果については、Ver2.2で結果データをURL経由でも引き継ぐフォールバックを追加しています。
