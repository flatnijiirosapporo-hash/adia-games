# にじフラ チャレンジ Ver2.5 - 継続支援・評価漏れ防止・経過確認版

## 起動方法
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. ゲームまたはSSTを選びます。

インストールや外部ライブラリは不要です。新規ゲームはオフラインで動作します。

## 参考情報
参考サイト: 特別支援教材開発研究所（TKK） https://tkk-fk.com/
確認日: 2026-08-26

TKKで公開されているゲーム系教材の「学習目的・ルール・操作の考え方」を参考にし、コード・画面・素材はにじフラ用に独自実装しています。TKKのHTML/CSS/JavaScriptや画像素材をコピーしたものではありません。

## 収録ゲーム
52種類。Ver2.1までのゲーム・フラトレ・運動あそび・危険予知・SST・10分チェック等は削除せず継続収録しています。



## Ver2.5 追加・強化内容（2026-08-26）

### 1. 今日の記録設定
- TOPで「児童名」「担当職員」を任意設定
- 一度設定すると、以後に開くゲーム/SST/A4評価シートへ引き継ぎ
- 過去の評価記録から児童名・担当職員を候補表示
- 共有端末向けに「設定をクリア」を用意
- URLにも児童名・担当職員を引き継ぐため、`file://` 直開き時でも直前の流れを維持しやすく改善

### 2. 評価漏れの見える化
- 記録管理に「未評価」件数を追加
- 「評価状況」フィルターを追加
- 「未評価だけ」でA4評価が未入力の記録をすぐ確認
- 児童数を集計表示
- 一部だけ記入した記録と完全未評価を表示上で区別

### 3. 児童別の経過
`child_summary.html` を追加しました。
- 児童名・期間を指定して記録を集約
- 記録件数、評価記入率、ゲーム/SST回数、最終実施日
- 活動カテゴリ別の実施回数
- 繰り返し実施した活動
- 保存された職員観察（◎/○/△）を軸別に見やすく集計
- 直近5件とその前5件を比較（十分な記録がある場合のみ）
- 最近の記録からA4編集・再印刷へ移動

### 4. 経過表示の評価上の安全性
- ◎=3、○=2、△=1への数値置換は画面表示上の集計だけに使用
- 「数値が高い＝能力が高い」とは扱わない
- 診断や能力判定には使用しない旨を画面上に明示
- 体調、環境、課題難易度、支援者、提示方法の影響を考慮し、A4観察メモと合わせて確認する設計

### 5. A4入力の再入力削減
- 児童名・担当職員を過去記録から候補表示
- TOPの「今日の記録設定」が未評価のA4に自動入力
- A4保存時の児童名・担当職員を次回用設定として保持

### 3. 集中モード
- 52ゲームと旧フラットゲームに集中モードを追加

- スマホで終了ボタンが初期状態から操作を妨げる問題をQA中に発見し修正

- 継続記録は従来どおりWindowsランチャーまたは通常のWebサーバー利用を推奨

### 5. A4印刷の1ページ保証を強化

- 印刷時のhtml/bodyサイズとSST記録のコンパクト表示を再調整
- SSTの実データ相当を入力した状態でA4縦1ページを確認

## Ver2.2 追加・強化内容（2026-08-26）

### 1. 結果・評価の記録管理
`records.html` を追加しました。
- 児童名で検索
- ゲーム・SST名で検索
- SST / ゲームの種類で絞り込み
- 開始日・終了日で期間指定
- 保存済み評価を一覧表示
- 過去のA4評価シートを再編集・再印刷
- 個別記録の削除
- 全記録削除は「削除」と入力した場合だけ実行
- 全記録CSV出力
- 絞り込み中だけCSV出力
- JSON完全バックアップ
- JSONバックアップ読込・復元

CSVには、実施日時、児童名、担当職員、活動名、客観結果、総合評価、各観察評価、観察メモ、次回のねらい、本人のふりかえり、記録IDを出力します。

### 2. 記録保存方式をVer2.2へ更新
- Ver2.1の結果記録を自動移行して読み込みます。
- A4評価欄を結果IDと関連付けて保存します。
- A4評価シートの入力は自動保存にも対応します。
- 旧Ver2.1の評価入力が残っている場合も読み込みます。
- 最大1000件を端末内に保存します。

### 3. 構造化SSTセッション
`sst_session.html` を追加しました。

SSTを「問題に正解する」だけで終わらせず、次の4段階で実施できます。
1. 今日のねらいを決める
2. 場面と見本を確認する
3. 3回練習して必要な支援量を記録する
4. 実生活で次に使う場面・合図・職員支援へつなげる

練習テーマ:
- 助けを求める
- 上手に断る
- 気持ちを伝える
- 聞く・会話を続ける
- 仲直り・やり直し
- 相手の立場
- 順番・待つ
- トラブル対応

各テーマは「基本」「実践」の場面を持ち、3試行ごとに以下の支援量を記録します。
- ◎ 自分で
- ○ 声かけ
- △ 見本・視覚支援
- — 中断・調整

本人が実際に言った言葉・行動も試行ごとに記録できます。終了後は共通A4評価シートへ連携します。

### 4. SSTの般化支援
構造化SSTの終了時に、以下を記録できます。
- 次にこのスキルを使う場面
- 本人が使う合図・ことば
- 職員の支援方法

これにより「教材内でできた」から「実生活で使う」までを1記録に残せます。

### 5. SST場面の読み上げ
構造化SSTにはブラウザの音声読み上げ機能を利用した「場面を読み上げ」を追加しています。
対応ブラウザ・端末に日本語音声がある場合に利用できます。未対応端末では使用できません。

### 6. A4結果・評価シート強化
- A4縦1枚
- 客観結果と職員評価を分離
- 児童名・担当職員
- 参加・指示理解・注意集中・判断切替・自己調整
- SST時は場面理解・相手視点・ことば/行動選択を追加
- 観察メモ
- 次回のねらい・支援方法
- 本人のふりかえり
- 総合評価
- 記録ID・保存元を印字
- 入力量に応じた自動コンパクト表示
- 入力内容の自動保存

### 7. アクセシビリティ
- キーボード操作時のフォーカスを見やすく表示

## 操作統一
- 各ゲームの開始は「スタート」に統一
- ゲーム開始後、最初のスタートボタンは非表示
- 終了型ゲームでは「もう1回」を表示
- 「もう1回」押下時に「周りにやりたい友達がいないか確認してね」を確認してから再開
- TOP以外にVer表記なし

## 推奨運用
1. 児童がゲームまたはSSTを実施
2. 終了後に「結果・評価を印刷」へ進む
3. 職員が観察評価・メモ・次回のねらいを入力
4. 必要に応じてA4印刷
5. `records.html` で未評価記録を確認し、`child_summary.html` で児童別の経過を振り返る
6. 定期的にJSONバックアップを保存
7. 集計が必要な場合はCSV出力

## 保存データについて
データは使用しているブラウザのローカルストレージに保存します。クラウド送信は行いません。
ブラウザのデータ消去、端末変更、別ブラウザ利用では自動的には引き継げません。JSONバックアップを利用してください。

児童名などの個人情報を入力する場合は、共有端末の管理、端末の紛失対策、バックアップファイルの保存先を事業所の個人情報管理ルールに沿って管理してください。

## 評価上の注意
ゲームの点数、正答率、成功・失敗だけで児童の能力や療育上の評価を決める仕様にはしていません。
ゲーム結果は客観結果として扱い、療育上の評価は、実際の行動、必要な支援量、場面理解、切り替え、自己調整、般化状況などを職員が観察して記録してください。

## Windowsでの推奨起動方法
記録履歴・A4評価・CSV/バックアップを継続利用する場合は、ZIP展開後に `START_NIJIFLA.bat` をダブルクリックしてください。

同梱の `start_nijifla.ps1` が `127.0.0.1` のローカルWebサーバーを起動し、ブラウザで自動的に開きます。外部ネットワークには公開しません。起動したPowerShell画面を閉じるとサーバーも終了します。

`index.html` を直接開く方法も残しています。ただし `file://` でのローカルストレージの扱いはブラウザ実装に依存するため、複数HTML間で長期の記録履歴を共有する用途ではローカルWebサーバー起動または通常のWebサーバーへの設置を推奨します。

ゲーム終了直後のA4結果については、Ver2.2で結果データをURL経由でも引き継ぐフォールバックを追加しています。
