[88] 全国・電車運転
- 8 regions x 3 difficulties = 24 courses, all selectable from the start
- Easy control: 加速 / ブレーキ
- Expert control: one-handle P5-P1 / N / B1-B7 / EB
- Forward pseudo-3D view; automatic platform / stop-line view at 200 m before station
- 100-point deduction system; 80+ pass; S/A/B/C/D ranks
- Arrival and departure both penalize early/late timing
- Stop-position scoring and stop-line overrun handling
- Multi-aspect signals: G / Y / YY / YR / R with advisory warning
- Red overrun: -30 + automatic emergency brake
- Station pass: -30 + automatic brake, then continue
- Opposing / lead / passing trains; challenge-only disruptions and recovery running
- Weather changes braking; six vehicle archetypes have different acceleration / max speed / brake / grade / weather stability
- TTS station announcements when SpeechSynthesis is available
- Six original local WAV SFX: chime / door open / door close / departure bell / speed warning / emergency
- Per-course BEST stores score + rank only in nijifla_train_driver_best_v1
- Schedules, distances, speed limits and signal placement are game-only compressed settings and are not reproductions of real operating data
